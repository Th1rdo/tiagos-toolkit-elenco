# Tiago's Toolkit: Elenco

Tokens a meio da sessão num gesto. Sem ficha: uma imagem, um nome e uma barra de vida do **Bar Brawl**.

- **Largar uma imagem do computador no mapa** → cartão (nome, vida, quantos, hostil/neutro/amigável, tamanho) →
  **Enter** → o ator e o token ficam criados **com a mesma imagem**, onde se largou. A imagem vai para
  `tiagos-toolkit-elenco/` (no Forge, para os teus assets).
- **Botão «Novo token»** (ferramentas dos tokens, ícone de pessoa com +) → o navegador de ficheiros normal → cartão →
  **clica no mapa** onde o queres (Esc ou botão direito cancela). Também há um atalho, sem tecla por omissão
  (Controlos → Elenco).
- **Vida**: «12» = 12 de 12; «8/20» = 8 de 20; vazio = sem barra. Fica numa barra «custom» do Bar Brawl, no próprio
  token — mexe-se como sempre.
- **Vários iguais**: «Quantos: 3» → Capanga 1, 2, 3, espalhados, cada um com a sua vida (um ator só).
- **Trocar a imagem**: largar uma imagem do computador **em cima de um token** troca a do token e a do ator.
- **As tuas barras**: no menu de um token teu (botão direito), o ícone de coração copia o estilo das barras dele
  (cores, posição, quem vê) para os tokens novos.
- Os atores criados ficam na pasta **«Criados em jogo»**.
